# C++ — Объектіге бағытталған бағдарламалау

## Практикалық сабақ №1

**Тақырып:** Бағдарламалауға және C++ тіліне кіріспе: бағдарламаның құрылымы, айнымалылар, деректер типтері және енгізу-шығару.

## Сабақтың мақсаты

C++ бағдарламалау тілінің негізгі ұғымдарымен танысу және қарапайым бағдарламалар құрастыру:

- C++ бағдарламасының құрылымы;
- айнымалыларды жариялау;
- негізгі деректер типтері;
- консоль арқылы мәлімет енгізу және шығару;
- қарапайым математикалық функцияларды қолдану.

## Қысқаша теория

### Негізгі ұғымдар

- **Бағдарлама** — компьютер орындауы үшін белгілі бір бағдарламалау тілінде жазылған командалар мен нұсқаулар жиынтығы.
- **Бағдарламалау тілі** — компьютер үшін бағдарламалар жазуға мүмкіндік беретін формалды тіл.
- **Айнымалы** — мәліметтерді сақтау үшін қолданылатын атауы бар жад аймағы.
- **Оператор** — белгілі бір әрекетті орындауға арналған команда.
- **Алгоритм** — тапсырманы орындауға немесе мәселені шешуге арналған нақты және реттелген әрекеттер тізбегі.
- **Алгоритмдеу** — белгілі бір мәселені шешудің алгоритмін құру процесі.
- **Компилятор** — C++ кодын компьютер орындай алатын машиналық кодқа айналдырады.
- **Интерпретатор** — бағдарламалық кодты орындау барысында түсіндіретін және өңдейтін бағдарлама.
- **Объектіге бағытталған бағдарламалау (OOP)** — бағдарламаны объектілер мен кластар арқылы құру әдісі.

### Алгоритмнің 5 қасиеті

1. Нақтылық
2. Реттілік
3. Дискреттілік
4. Нәтижелілік
5. Аяқтаушылық

### Алгоритмді ұсынудың 3 жолы

1. Сөздік сипаттау
2. Блок-схема
3. Бағдарламалау тілі арқылы

## C++ туралы

C++ — жоғары өнімділікке ие, кеңінен қолданылатын бағдарламалау тілі. Ол:

- бағдарламалық қамтамасыз етуді әзірлеуде;
- ойындар жасауда;
- жүйелік бағдарламалауда;
- робототехникада;
- компьютерлік инженерияда;
- алгоритмдер мен деректер құрылымдарын оқытуда

қолданылады.

C++ бағдарламалау тілі 1980-жылдардың басында пайда болды.

## C++ бағдарламасының негізгі құрылымы

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, World!";
    return 0;
}
```

### Негізгі элементтер

| Элемент | Қызметі |
|---|---|
| `#include <iostream>` | Енгізу және шығару операцияларымен жұмыс істеуге мүмкіндік береді |
| `using namespace std;` | `std` кеңістігіндегі стандартты объектілерді қысқаша жазуға мүмкіндік береді |
| `int main()` | Бағдарламаның орындалуы басталатын негізгі функция |
| `{ }` | Функцияның денесін көрсетеді |
| `cout` | Экранға ақпарат шығарады |
| `cin` | Пайдаланушыдан мәлімет енгізеді |
| `return 0;` | Бағдарламаның сәтті аяқталғанын білдіреді |
| `endl` | Келесі жолға көшіреді |
| `#include <string>` | `string` типін қолдану үшін қосылады |
| `#include <cmath>` | Математикалық функцияларды пайдалану үшін қажет |

## Негізгі деректер типтері

| Деректер типі | Қолданылуы | Мысал |
|---|---|---|
| `int` | Бүтін сандар | `25` |
| `double` | Бөлшек сандар | `25.5` |
| `float` | Бөлшек сандар | `3.14` |
| `char` | Бір символ | `'A'` |
| `bool` | Логикалық мән | `true` |
| `string` | Мәтін | `"Hello"` |

cout << "Enter two numbers: ";

# Практикалық тапсырмалар

## Практика №1 — Ақпарат шығару

Бағдарламаны өзгертіп, экранға келесі ақпаратты шығарыңыз:

```text
My name is ...
I am a student.
I study programming.
```

## Практика №2 — Студент туралы ақпарат

Берілген бағдарламаны өз мәліметтеріңізге өзгертіңіз:

```cpp
#include <iostream>
#include <string>
using namespace std;

int main()
{
    string name = "Aruzhan";
    int age = 18;
    double gpa = 3.5;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "GPA: " << gpa << endl;

    return 0;
}
```

Өзгертілетін мәліметтер:

- аты-жөні;
- жасы;
- GPA мәні.

## Практика №3 — Екі сан

Екі санның:

- қосындысын;
- айырмасын;
- көбейтіндісін

экранға шығарыңыз.

## Практика №4 — Жас

Пайдаланушының жасын енгізетін және келесі түрде нәтиже шығаратын бағдарлама жазыңыз:

```text
You are 18 years old.
```

## Практика №5 — Тік төртбұрыш

Тік төртбұрыштың ұзындығы мен енін енгізіңіз.

Есептеңіз:

- периметрін;
- ауданын.

## Практика №6 — Үш сан

Үш бүтін сан енгізіп:

- олардың қосындысын;
- орташа арифметикалық мәнін

табыңыз.

## Практика №7 — Сағатты минутқа айналдыру

Сағат санын енгізіңіз. Оны минутқа айналдырыңыз.

## Практика №8 — Қозғалыс уақыты

Қашықтық пен жылдамдықты енгізіңіз.

Жолға кететін уақытты есептеңіз.

## Практика №9 — 4 пәннің орташа бағасы

4 пән бойынша бағаларды енгізіңіз:

- Programming
- Mathematics
- English
- Physics

Орташа бағасын есептеңіз.

## Практика №10 — «Кафедегі тапсырыс»

Пайдаланушыдан:

- тағам бағасы;
- тағам саны;
- сусын бағасы;
- сусын саны

енгізіледі.

Жалпы соманы есептеңіз.

## Практика №11 — «Кино»

Бір билет бағасы мен билеттер санын енгізіңіз.

Жалпы соманы есептеңіз.

Қосымша:

- попкорн бағасы;
- сусын бағасы

енгізілсін.

Соңында киноға кеткен жалпы соманы шығарыңыз.

## Практика №12 — 5 күндегі шығын

Студенттің 5 күндегі шығындарын енгізіңіз:

- Monday
- Tuesday
- Wednesday
- Thursday
- Friday

Есептеңіз:

- жалпы шығын;
- орташа күндік шығын.

## Практика №13 — Функцияның мәнін есептеу

Берілген функция:

```text
y = 3x² - 5x + 2
```

`x` мәнін енгізіп, `y` мәнін есептеңіз.

## Практика №14 — Функция

Берілген өрнек:

```text
z = 2x² + 3y - 5
```

`x` және `y` мәндерін енгізіп, өрнектің мәнін есептеңіз.

## Практика №15 — Өрнек мәнін есептеу

Берілген математикалық өрнектің мәнін табыңыз. `x` мәнін енгізіп, нәтижені есептеңіз.

> Ескерту: PDF-тегі бұл тапсырманың формуласы мәтіндік түрде толық оқылмаған.

## Практика №16 — Үшбұрыш ауданы

Үшбұрыштың үш қабырғасы берілген.

Герон формуласы арқылы үшбұрыштың ауданын табыңыз.

Жарты периметр:

```text
p = (a + b + c) / 2
```

Аудан:

```text
S = √(p(p-a)(p-b)(p-c))
```

## Практика №17 — `x` арқылы `y` табу

Бағдарлама `x` мәнін енгізіп, `y` мәнін есептеуі керек.

> Ескерту: PDF-тегі №17 тапсырманың формуласы мәтіннен толық анықталмайды.

## Практика №18 — Қозғалыс жолы

Дене бастапқы жылдамдықпен қозғалады.

Берілген:

- `v₀` — бастапқы жылдамдық;
- `a` — үдеу;
- `t` — уақыт.

Жолды есептеңіз.

## Практика №19 — Шеңбер радиусы

Шеңбердің ауданы `S` берілген.

Радиусты табыңыз:

```text
r = √(S / π)
```

## Практика №20 — Функция

Берілген өрнек:

```text
y = x⁵
```

`x` мәнін енгізіп, `y` мәнін табыңыз.
